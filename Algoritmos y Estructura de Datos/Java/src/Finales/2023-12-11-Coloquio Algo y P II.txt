2)a) Si nodo = 0 => suma 0, si no tiene hijos, suma 1 y sino suma lass hojas del hijo izquierdo y el derecho. Entonces el algortimo es:

int contarHojas(Nodo nodo) {
    
    // Caso base: arbol vacio
    
    if (nodo == null) {
        return 0;
    }

    // Caso base: es una hoja sin hijos

    if (nodo.izquierdo == null && nodo.derecho == null) {
        return 1;
    }

    // Paso recursivo: sumatoria de las hojas de los subarboles

    return contarHojas(nodo.izquierdo) + contarHojas(nodo.derecho);
}

La eficiencia del programa es de O(n) ya que el algoritmo debe visitar todos los nodos para poder ver si son hojas o no.

3) a) Árbol de Expansión de Coste Mínimo (MST)
Resultado del Árbol: El árbol resultante está formado por las siguientes aristas:
1. (4, 5) - Peso: 80
2. (3, 4) - Peso: 100
3. (1, 2) - Peso: 200
4. (1, 3) - Peso: 200
5. (5, 6) - Peso: 200
Costo Total: 80+100+200+200+200=780

Paso a Paso (Traza del Algoritmo de Prim)
Asumimos que iniciamos en el Nodo 1. (Nota: El algoritmo de Prim mantiene una lista de "candidatos" (aristas) que conectan nodos visitados con no visitados, eligiendo siempre la menor).
1. Inicio: {1}.
    ◦ Candidatos: (1,2)=200, (1,3)=200, (1,4)=250.
    ◦ Selección: (1, 2) con peso 200. (Podría ser (1,3), da igual, elegimos este).
    ◦ Nodos en MST: {1, 2}.
2. Desde {1, 2}:
    ◦ Nuevos candidatos (vecinos de 2): (2,3)=200, (2,4)=250.
    ◦ Candidatos acumulados: (1,3)=200, (1,4)=250, (2,3)=200, (2,4)=250.
    ◦ Selección: (1, 3) con peso 200. (Descarta (2,3) después porque conectaría dos nodos ya visitados).
    ◦ Nodos en MST: {1, 2, 3}.
3. Desde {1, 2, 3}:
    ◦ Nuevos candidatos (vecinos de 3): (3,4)=100, (3,5)=100, (3,6)=400.
    ◦ Selección: (3, 4) con peso 100 (es la menor de todas las disponibles).
    ◦ Nodos en MST: {1, 2, 3, 4}.
4. Desde {1, 2, 3, 4}:
    ◦ Nuevos candidatos (vecinos de 4): (4,5)=80, (4,6)=250.
    ◦ Selección: (4, 5) con peso 80. (Es la menor absoluta).
    ◦ Nodos en MST: {1, 2, 3, 4, 5}.
    ◦ (Nota: La arista (3,5) de peso 100 se descarta porque el 5 ya fue visitado por un camino más barato).
5. Desde {1, 2, 3, 4, 5}:
    ◦ Nuevos candidatos (vecinos de 5): (5,6)=200.
    ◦ Candidatos disponibles hacia el 6: (3,6)=400, (4,6)=250, (5,6)=200.
    ◦ Selección: (5, 6) con peso 200.
    ◦ Nodos en MST: {1, 2, 3, 4, 5, 6}. ¡Fin!

Descripción del Algoritmo (Prim): El algoritmo comienza con un nodo arbitrario y hace crecer el árbol un vértice a la vez. En cada paso, agrega la arista de menor peso que conecta un vértice del árbol con uno que aún no está en el árbol (estrategia Greedy/Voraz),.
Estructuras Utilizadas:
1. Grafo: Representado mediante Listas de Adyacencia (para eficiencia si el grafo es disperso) o Matriz de Adyacencia.
2. Estructura Auxiliar (Clave): Una Cola de Prioridad (Min-Heap).
    ◦ Esta estructura es fundamental para organizar los candidatos.
3. Arreglos Auxiliares:
    ◦ distancia[]: Guarda el peso mínimo actual para conectar cada nodo al árbol.
    ◦ visitado[]: Booleano para saber qué nodos ya están en el MST.
    ◦ padre[]: Para reconstruir el árbol final.
Organización de los Candidatos: El algoritmo organiza los candidatos (nodos adyacentes no visitados) en la Cola de Prioridad (Min-Heap) ordenados por el peso de la arista. Esto permite obtener el siguiente candidato óptimo (menor costo) en tiempo constante o logarítmico (O(1) para el mínimo, O(logV) para extraerlo)

3)b) Un punto de articulación (o vértice de corte) es un vértice que, si se elimina junto con sus aristas incidentes, provoca que el grafo se separe en dos o más componentes aisladas.
Ejemplo: Imagina un grafo con forma de "reloj de arena" o "moño":
• Tienes un triángulo a la izquierda (Nodos A, B, C conectados entre sí).
• Tienes un triángulo a la derecha (Nodos C, D, E conectados entre sí).
• El Nodo C es el único nexo entre ambos triángulos.
Si eliminas el Nodo C, el grafo se rompe en dos pedazos separados (el triángulo {A,B} y el triángulo {D,E}). Por lo tanto, C es un punto de articulación.
